# Public name "Codino"; Clawd not distributed

Anthropic's Claude Code terms forbid using Claude Code or Anthropic names or logos in a third-party product name, and they say nothing about the Clawd mascot. The project is therefore named **Codino** ("code" + the Arduino-style "-ino"; Italian for "little ponytail"), replacing the working name "Claudino", and mentions Claude only descriptively ("works with Claude Code"). The default Character Theme uses an original mascot. Clawd is a separately loaded sprite pack that the project does not ship until Anthropic grants written permission.
